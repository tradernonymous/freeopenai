HOW TO READ THIS
  Each phase says: what lands, which NEURA ids it closes, what you have to do
  yourself, which app or service is involved, and how it is verified. "Green
  EXE" always means the Desktop workflow finishing with Installer + MSI +
  Portable artifacts, after cargo test and the node suite have passed.

  The standing loop for every phase, unchanged:
    1. git pull --rebase
    2. build it
    3. node --test  +  npm run lint  +  npx tsc --noEmit  +  npx vite build
    4. node scripts/run-evals.js   (must stay 48/48)
    5. git add only the intended files, commit, push origin HEAD:main
    6. watch the Desktop run to green; a red build gets a NEW fix commit,
       never a force-push
    7. report what changed

PART 2 -- YOURS, NOT MINE (5 items, none of them code)
-------------------------------------------------------------------------------
NEURA-001  CODE SIGNING                          service: Azure, or any CA
  Why: without it Windows SmartScreen warns every person who installs.
  Either: a .pfx file -> repository secrets WINDOWS_CERTIFICATE (base64) and
  WINDOWS_CERTIFICATE_PASSWORD.
  Or: Azure Trusted Signing (about US$10/month) -> secrets AZURE_TENANT_ID,
  AZURE_CLIENT_ID, AZURE_CLIENT_SECRET and variables TRUSTED_SIGNING_ACCOUNT,
  TRUSTED_SIGNING_PROFILE, TRUSTED_SIGNING_ENDPOINT.
  CI already handles both paths. Full steps: docs/desktop.md -> Signing.

NEURA-002  HUGGING FACE OAUTH APP                service: huggingface.co
  Register at huggingface.co/settings/applications/new
    redirect  http://127.0.0.1:47823/hf/callback
    scopes    openid profile read-repos inference-api
  Then:  gh variable set NEURAOS_HF_CLIENT_ID --body <client-id>
  (or paste the id in Settings -> Connectors). Turns sign-in from "paste a
  token" into one click.

NEURA-003  UPDATE-SIGNING KEY                    service: none, local
  The four commands in docs/desktop.md -> Update signing. I am blocked from
  writing into your key folder, so these are yours to run. Back up the key and
  its password. Until then updates are checked by sha256 only.

NEURA-004  LOGO FILE                             app: any image editor
  assets/branding/neuraos-logo.png -- emblem only, no text, no background,
  square, 512px or larger. One file replaces the icon everywhere: web, APK,
  desktop, tray.

NEURA-042  PICK THE WHISPER PATHS                app: NeuraOS -> Settings
  The binary and models are on D: already (Part 1). Settings -> Dictation,
  choose Release\whisper-cli.exe and ggml-base.en.bin. Nothing to download.

PART 6 -- KNOWN LIMITS, SAID PLAINLY
-------------------------------------------------------------------------------
  - Flux and Qwen-Image do not fit 4 GB of VRAM. Even at Q4 they need roughly
    12 GB across the weights and a separate text encoder; they will run by
    offloading to RAM, at minutes per image. SD 1.5 is the model that actually
    works on this machine.
  - The turbo whisper model is too slow on this CPU (49s of encode for 1s of
    audio). base.en is the right choice here.
  - The approval menu governs the CODING AGENT. A chat turn's own gate is a
    static per-tool rule in tools.js and does not consult that setting yet --
    worth unifying, and not yet done.
  - Remote MCP apps get the tool result as text only.
  - Maestro (the Android UI tests) is non-blocking in CI by design.
  - 106 lint warnings, 0 errors. They are unused catch bindings and the like,
    inherited, and none of them is a bug.
