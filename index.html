How It Works

  • No API keys — Sign in with Google, Telegram, or Magic Key
  • User-pays model — Each user covers their own AI costs
  • Serverless — No setup required, works immediately
  • OpenAI models — GPT-6 Astra, the GPT-5.6 and GPT-4o families via Puter.js
  • Image generation — Toggle the image icon next to the input to generate one instead of chatting
  • Free tier — Generous free usage limits
  • Palette — Ctrl+P jumps to any model or action; Enter runs, Esc closes
  • Interrupt — Esc stops a running reply; Enter sends
  • Editing — Ctrl+A/E move, Ctrl+K/U/W delete, Alt+letter words, Ctrl+G stops
  • Gallery — Every generated image lands in the Gallery view, newest first
